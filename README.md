# SoSGB_WindmillETA

## 日本語

『牧場物語 Let's！風のグランドバザール』のModです。

風車で加工するとき、残り時間に加えて加工が完了するゲーム内日時を表示します。  
完了予定が当日中の場合は時刻のみ、翌日以降の場合は日付と時刻を表示します。

加工時間やゲームバランスそのものは変更しません。

## English

A mod for **STORY OF SEASONS: Grand Bazaar** that displays the in-game date and time when windmill processing will finish, in addition to the remaining processing time.  
If completion is expected on the same day, only the time is shown.  
For later dates, both the date and time are displayed.

This mod does not change processing times or game balance.

### Language support

Currently designed for the Japanese UI only.  
The estimated completion date/time is displayed in Japanese format.

### Installation

Requires [BepInEx 6 IL2CPP](https://www.nexusmods.com/storyofseasonsgrandbazaar/mods/17).  
Download `WindmillETA.dll` from [Releases](../../releases) and place it in:

`Steam/steamapps/common/STORY OF SEASONS Grand Bazaar/BepInEx/plugins/`
